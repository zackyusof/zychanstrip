# Meter display update control

Enhance OUT uses 20 LED levels in each column, −48 to 0 dBFS inclusive.
The meter-page UPDATE rotary control sets the editor GUI timer interval to 16–500 ms, default 33 ms. Double-click resets it to 33 ms. The setting lasts for the current editor lifetime. It updates rack meters when the rack is visible and the analyser when the meter page is visible. Audio metering and DSP keep running normally; display smoothing on the analyser is adjusted for the interval.

The UPDATE control sits after the right channel bar, between the L/R meter bank and phase scope. Its red cap, dark skirt and cream pointer follow the supplied reference. Tick labels show actual millisecond values (16, 33, 50, 100, 200, 500), positioned using the slider mapping. The shared scale caption carries the ms unit.
